# SimpleMemKitty 🐱
A lightweight, open-source Windows memory monitoring & cleaning tool built with Python.

---

## ✨ Key Features
- **Lightweight & Efficient**: Minimal resource usage, runs quietly without bogging down your system
- **Safe & Reliable**: Only frees idle RAM—no forced process kills or risky system changes
- **Open Source**: Fully transparent codebase, free to use, modify, and share
- **Simple to Use**: One-click cleaning + real-time memory monitoring, no complex setup
- **Cat-like Agility**: Nimble, unobtrusive design that stays out of your way

---

## 🚀 Quick Start
### Prerequisites
- Windows 7/10/11
- Python 3.8+

### Run the Tool
1. Clone the repository:
   ```bash
   git clone https://github.com/Hrecer/SimpleMemKitty.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch:
   ```bash
   python main.py
   ```

---

## 📝 Usage Notes
- Run as **Administrator** for full memory monitoring/cleaning access
- This tool only reclaims unused memory to avoid interrupting active apps
